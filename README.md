# Story Engine

A story simulation for grades 3–5. Learners choose **when** Charles is at the beach (day or night) and **what happens** (a lost child or a fire). The story pauses at the decision moment, and learners choose whether Charles is **brave** or **scared**. Then they see how the story and its ending change.

**Learning goal:** understand how story elements (character, setting, problem) affect what happens in a story.

**Model (rule-based):** three variables, two values each (8 stories).
- Brave: acts fast in a safe way (warns others, gets a grown-up, calls for help).
- Scared: waits, so the problem grows.
- Night: no lifeguard, so help is slower and waiting costs more.

Each ending shows two meters: **Safe** (did everyone stay safe?) and **Fast** (how fast help came).

Open `index.html` in a browser. Narration audio is in `audio/`.
